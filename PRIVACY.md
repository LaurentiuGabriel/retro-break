# Privacy policy

retro-break collects no data and sends none.

- **What it reads:** only the file names in the ROM folder you configure, to pick a game. It doesn't read your prompts, Claude's replies, your code or your other files.
- **What it sends:** nothing. There is no telemetry, analytics or tracking. The only network request is a one-time download of an emulator from its official GitHub release; that request carries no data about you beyond what any download does (your IP address, seen by GitHub).
- **What it stores:** the emulators, and the emulators' own saves and settings, in `%LOCALAPPDATA%\retro-break\emulators` on your computer. Delete that folder to remove them.

Questions: open an issue at https://github.com/LaurentiuGabriel/retro-break/issues.
